# 🚍 Doon E-Bus GPS Tracking System

A frontend-based prototype of a smart bus tracking system designed to improve public transport experience in a smart city.

---

## 📌 About the Project

This project is a concept-based web application that simulates a smart electric bus tracking system. It provides a modern and user-friendly interface for features like bus tracking, estimated arrival time (ETA), seat availability, and ticket booking.

The project is currently in the design and development stage and focuses on UI/UX and system concept. Future updates will include real-time GPS tracking and backend integration.

---

## 🔥 Features

- 📍 Bus tracking simulation  
- ⏱️ Estimated arrival time (ETA) display  
- 💺 Seat availability interface  
- 🎟️ Ticket booking UI  
- 🔔 Smart notification concept  

---

## 💻 Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## 🚀 How to Run
